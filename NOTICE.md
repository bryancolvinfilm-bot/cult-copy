# Independent third-party project

Cult Copy is an independent, third-party open-source project that provides
clipboard sharing between paired computers on a local network.

This project has no relation to Duet Display. It is not affiliated with,
endorsed by, sponsored by, or maintained by Duet Display or its developers.
References to Duet Display describe a possible use case for this separate
helper; they do not indicate an official product, partnership, or integration.

Duet Display is not required. This app does not modify it, use its APIs, or
depend on a Duet Display account. Computers communicate directly over a
reachable local network after pairing.
